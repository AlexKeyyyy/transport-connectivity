Срез сформирован 2026-10-09 для 10 городов ЦФО. Внешний набор маршрутов охватывает все направленные пары между этими городами и три типа транспорта; значения не моделировались вручную.

| Файл | Источник | Записей | Что содержит |
|---|---|---:|---|
| `intercity_connectivity_sample.csv` | «Если быть точным», версия 2026-06-29 | 270 | Исходные измерения автомобильных, железнодорожных и авиационных маршрутов между пилотными городами |
| `cities.csv` | OpenStreetMap Overpass; регион и население — внешний датасет | 10 | OSM ID, название, тип места, координаты и доступные атрибуты городов |

## Основные поля

### `intercity_connectivity_sample.csv`

Формат исходника сохранён: кодировка UTF-8, разделитель `;`, 22 поля. Одна строка — направленный маршрут для пары городов и одного `transport_type` (`road`, `rail`, `air`). `distance_km` — километры; `distance_hr` — часы, рассчитанные авторами источника по средней скорости, а не расписание поездки. `missing_reason` сообщает, почему измерение отсутствует; пропущенные значения расстояния/времени оставлены незаполненными. `oktmo_*` и `sber_territory_id_*` — коды городов источника, `population_*` — человек, `lat_*`/`lon_*` — координаты в градусах. `source` и `comment` — исходные поясняющие поля. Все 22 исходных столбца приведены в `data_profile.json`.

### `cities.csv`

`city_id` — локальный стабильный ключ, производный от OSM типа и ID; `osm_id` — исходная пара тип/ID OSM; `name`, `place_type`, `latitude`, `longitude` описывают найденный объект OSM; координаты WGS84 в градусах. `region` и `population` взяты из внешнего датасета связности; население — человек. Источник каждой строки указан в `source`.

### `road_segments_sample.geojson`

Один Feature — один OSM way. `osm_way_id` — внешний ID; `highway_type` — класс дороги по OSM; `name` — имя, если размечено; `oneway` — тег направления; `maxspeed` — ограничение/значение скорости в исходном формате OSM (может быть пусто); `surface` — покрытие. Геометрия LineString использует порядок `[долгота, широта]`. Отсутствующие теги не заполнялись.

### `route_measurements.csv`

Одна строка — результат OSRM между двумя разными городами. `distance_m` — метры по быстрейшему маршруту, `duration_sec` — секунды; `router` — endpoint, `calculated_at` — время запроса UTC, `data_version` — версия данных, только если её вернул API. Это измерение поездки, не готовое ребро аналитического графа.

### `public_transport_sample.json`

Выгрузки расписаний пока нет: `records` пуст, статус `not_fetched_no_api_key`. Файл оставлен для явной фиксации ограничения, он не содержит синтетических расписаний.

## Проверки

Подробный машинный отчёт — `data_profile.json`: пропуски, типы, дубликаты, диапазоны, проверка координат и связей `city_id`, число столбцов и размер каждого файла. В датасете связности отсутствует расстояние/время в 90 строках, причина передана исходным `missing_reason`; в дорожной выборке некоторые необязательные теги отсутствуют. В OSRM ответе поле `data_version` не предоставлено. Ничего из этого не заполнялось.

Повторить получение и анализ можно командами из корня репозитория:

```bash

py scripts/data/profile_samples.py
```
