# ADR 0002. Идентичность города: Sber ID и воспроизводимый UUID5

Статус: принято. Дата: 13 ноября 2026 года. Задача: [#4](https://github.com/AlexKeyyyy/transport-connectivity/issues/4);
правило согласовано в контракте данных ([data-contract.md](../data-contract.md), раздел 2).

## Контекст

Источники называют один и тот же город по-разному: CSV связности — Sber ID и ОКТМО,
OpenStreetMap — идентификатором объекта, Яндекс Расписания — своим кодом. Названия
повторяются (в России несколько городов с одинаковым именем) и пишутся по-разному.
Повторная загрузка не должна менять ключи и создавать дубликаты.

## Решение

- Ключ источника для полного CSV — Sber ID (`sber_territory_id_*`). Автоматической
  подстановки ОКТМО вместо отсутствующего Sber ID нет: такая строка отклоняется.
- Внутренний ключ `city_id = uuid5(NAMESPACE_CITY, 'sber_territory:<Sber ID>')`,
  где `NAMESPACE_CITY = de98ebe7-8f16-5a7f-b476-6c58b1f92076`
  (`uuid5(NAMESPACE_URL, 'urn:transport-graph:namespace:city')`). Константа не меняется.
- Все внешние коды хранятся строками в `city_external_id` вместе с пространством имён;
  пара (пространство имён, код) указывает ровно на один город.
- Неоднозначное соответствие кодов не записывается, а попадает в отчёт запуска.

## Рассмотренные варианты

- Последовательный `bigint identity`: компактнее и лучше для индекса, но номер зависит
  от порядка загрузки — повторная сборка базы даст другие ключи, и ссылки из выгрузок
  Neo4j/Elasticsearch и отчётов перестанут совпадать.
- Случайный UUID: не воспроизводится между запусками.
- Название с регионом: не уникально и меняется при исправлении написания.

## Последствия

- Одинаковый вход даёт одинаковые ключи на любой машине; это проверяется сравнением
  SHA-256 выходных файлов двух запусков.
- UUID5 не упорядочен по времени, поэтому вставки в индекс разбросаны. Для сотен городов
  и сотни тысяч измерений это несущественно; при росте на порядки стоит пересмотреть.
- Город из другого источника без Sber ID сначала сопоставляется существующему городу
  отдельной процедурой (crosswalk) — новый город по названию не создаётся.
