# Предварительный срез данных проекта Transport Connectivity

## О проекте

Мы изучаем, насколько города России связаны между собой разными видами транспорта. В будущем города будут вершинами графа, а транспортные связи — его рёбрами. Этот пакет показывает исходные данные, на которых можно начать проектирование такой модели.

## Источники

- **«Если быть точным»** — открытый набор транспортной связности крупнейших городов России, версия от 29 июня 2026 года (CC BY 4.0): [страница и описание](https://tochno.st/datasets/intercity_connectivity). В источнике использованы OSM, OSRM, СберИндекс, OurAirports, Aviastats и Росавиация.
- **OpenStreetMap** — названия, координаты и типы выбранных городов, а также небольшой срез дорожных объектов. Геоданные доступны по ODbL; атрибуция: OpenStreetMap contributors.
- **OSRM** — расчёт автомобильных расстояний и времени через публичный Table Service. Это оценка маршрута по дорожному графу сервиса, а не расписание.
- **Яндекс Расписания** — планируемый источник поездов и автобусов. Ключ API при подготовке пакета отсутствовал, поэтому записи расписаний не получены.

Выбраны 10 городов Центрального федерального округа: Москва, Тверь, Ярославль, Владимир, Рязань, Тула, Калуга, Смоленск, Брянск и Орёл.

## Что находится в файлах

| Файл | Записей | Что означает одна запись |
|---|---:|---|
| `intercity_connectivity_sample.csv` | 270 | Один направленный маршрут от города к городу для одного вида транспорта: авто, поезд или авиация. Это готовые измерения источника, не наши расчёты. |
| `cities.csv` | 10 | Один найденный в OpenStreetMap населённый пункт: внешний OSM ID, название, тип и координаты. Регион и население добавлены из набора связности. |
| `road_segments_sample.geojson` | 150 | Один участок дороги OSM в небольшом районе Москвы с геометрией и доступными тегами. Пустые теги означают, что OSM их не указывает. |
| `route_measurements.csv` | 90 | Один рассчитанный OSRM автомобильный маршрут между двумя разными городами: расстояние в метрах и время в секундах. Это измерение поездки, а не автоматическое ребро графа. |
| `public_transport_sample.json` | 0 | Сообщает, что данные Яндекс Расписаний не загружались: API-ключ отсутствовал. Файл не содержит вымышленных маршрутов. |
| `data_profile.json` | — | Отчёт о структуре и качестве полученных файлов. |

В датасете связности каждая пара направленная: Москва → Тверь и Тверь → Москва — разные наблюдения. Из 270 записей 90 не имеют значения расстояния/времени; первоисточник указывает причину в `missing_reason`. Эти значения оставлены пустыми. В OSRM поле версии дорожных данных не вернулось. Теги имени, односторонности, скорости и покрытия в OSM иногда отсутствуют.

## Какие поля пригодятся графу

- Внешние идентификаторы, названия и координаты связывают сведения о городе между наборами.
- Направление «откуда → куда» и вид транспорта задают тип связи.
- Расстояние и время поездки можно использовать как разные веса/измерения доступности.
- OSM ID дороги, класс, направление движения и геометрия описывают дорожные объекты детальнее.
- Пропуски, причины их возникновения и источник измерения нужно сохранять отдельно; значения из разных источников не следует смешивать без проверки.

## Что будем собирать дальше

Расширять выборку городов и дорожных объектов, проверять согласованность идентификаторов, получать дополнительные данные расписаний при наличии доступа к API и сравнивать источники расстояний/времени. Полная сеть дорог и аналитические метрики графа в этот демонстрационный срез не входят.
