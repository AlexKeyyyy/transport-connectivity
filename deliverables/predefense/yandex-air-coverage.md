# Покрытие авиационного графа

Для [снимка Яндекс Расписаний](../../docs/yandex-schedules-plan.md) на
**1 декабря 2026 года** найдено **482 направленные связи** по **1 157
станционным вариантам поездки**. У **72 из 180** городов есть входящая
или исходящая авиасвязь с другим городом проекта.

[PDF-слайд для блока 10–11](yandex-air-coverage-slide.pdf).
Дополняет основной эксперимент [#43](https://github.com/AlexKeyyyy/transport-connectivity/issues/43).

## Какие города и вылеты попали в граф

| Покрытие городов | Количество |
|---|---:|
| Есть связь с другим городом проекта | 72 |
| В справочнике есть аэропорт, связи на эту дату не наблюдали | 18 |
| Город сопоставлен, аэропорта в справочнике нет | 89 |
| Город не сопоставлен со справочником | 1 |
| Всего | 180 |

На 90 городов с аэропортами приходится 104 записи аэропортов.
Из **1 609 уникальных отправлений** у **1 144** есть подходящий более поздний
прилёт того же UID на другой станции. Они дают 1 157 станционных вариантов,
которые агрегируются в 482 городские связи. У **463** отправлений записи
о прилёте с тем же UID в сохранённом окне нет. У **двух** есть только
более ранний прилёт в тот же аэропорт.

## Что известно о 465 вылетах без подходящего прилёта

Сверили последнюю часть названия нитки со справочниками городов и станций.
В **361** случае название встречается только у зарубежных пунктов, в **96**
совпало с российским пунктом за пределами списка проекта, в **семи** — с
городом проекта. Одно название осталось без совпадения. Название нитки даёт
подсказку о конечном пункте. Для подтверждения конкретного прилёта нужна
станционная запись. Прилёты на предыдущую местную дату в снимок не входили.
По сохранённым ответам нельзя подтвердить случаи пропуска по этой причине.

## Насколько меняется «Без Москвы» при добавлении трёх связей

Из семи совпадений с названиями городов проекта у четырёх пар уже есть
наблюдаемая связь. Остальные три пары — Киров → Москва, Сочи → Ярославль и
Сочи → Пенза — взяли для проверки чувствительности. Добавили их условно
только в расчёт и сравнили те же направленные пары среди 179 городов без Москвы.

| Вариант | До удаления Москвы | После удаления | Потеря |
|---|---:|---:|---:|
| Наблюдаемый авиаграф | 4 900 | 3 660 | 1 240 (25,3%) |
| Условно добавлены три связи | 4 900 | 3 720 | 1 180 (24,1%) |

Все 60 дополнительно достижимых пар во втором варианте ведут в Пензу.
Этот расчёт показывает чувствительность к трём выбранным связям на одной
дате. Устойчивость вывода между датами предстоит проверить на отдельном снимке.

## Как повторить

Запустите команду из корня репозитория с установленным пакетом.

```bash
python scripts/data/audit_rasp_air.py --raw-dir data/raw/yandex_rasp_20261201
```

Для снимков из другой рабочей копии передайте `--cities-dir`, `--rasp-dir`
и `--raw-dir`. Без `--raw-dir` команда печатает баланс из проверенных
нормализованных файлов и отчётов. С этим параметром она дополнительно сверяет
SHA-256 сохранённых ответов и повторяет классификацию по названиям.

Для проверки чувствительности используйте чистую функцию `compare_reachability`
из [PR #44](https://github.com/AlexKeyyyy/transport-connectivity/pull/44).
Запустите этот код из рабочего каталога со снимками и с установленным кодом #43.

```python
import csv
from pathlib import Path
from uuid import UUID

from transport_connectivity.air_resilience import MOSCOW_ID, compare_reachability

root = Path("data/normalized")
with (root / "tochno_intercity_v20260629/cities.csv").open(encoding="utf-8", newline="") as file:
    cities = {row["name"]: UUID(row["city_id"]) for row in csv.DictReader(file)}
with (root / "yandex_rasp_20261201/direct_links.csv").open(encoding="utf-8", newline="") as file:
    links = {
        (UUID(row["from_city_id"]), UUID(row["to_city_id"]))
        for row in csv.DictReader(file)
        if row["transport_type"] == "air"
    }
candidates = [("Киров", "Москва"), ("Сочи", "Ярославль"), ("Сочи", "Пенза")]
added = {(cities[origin], cities[target]) for origin, target in candidates}
print(compare_reachability(set(cities.values()), links, MOSCOW_ID))
print(compare_reachability(set(cities.values()), links | added, MOSCOW_ID))
```
