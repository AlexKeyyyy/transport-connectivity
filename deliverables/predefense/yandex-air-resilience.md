# Яндекс Расписания. Авиационный сценарий «Без Москвы»

В графе авиасвязей по расписанию на **1 декабря 2026 года** удаление Москвы
сократило число достижимых направленных пар с **4 900 до 3 660**. Потеря составила
**1 240 пар, или 25,3%** от исходно достижимых.

## Воспроизведение

Запустите команду из корня репозитория в окружении Python 3.12+ с установленным пакетом.

```bash
python -m transport_connectivity.cli rasp-air-resilience --date 2026-12-01
```

Из отдельного worktree передайте `--cities-dir` и `--rasp-dir` с путями к
сохранённым каталогам. По умолчанию команда читает
`data/normalized/tochno_intercity_v20260629/` и
`data/normalized/yandex_rasp_20261201/`. В каждом каталоге нужен
`run-report.json`. Команда работает офлайн и печатает результат в JSON.
[Подготовка снимков](../../data/README.md).

| Файл | Назначение | SHA-256 |
|---|---|---|
| `cities.csv` | Вершины из справочника «Если быть точным», версия 20260629 | `2c41900baaf94e26cc95df5f8bc19b70d6964066808cf9e514a93eeabf969e80` |
| `direct_links.csv` | Прямые связи Яндекс Расписаний на 1 декабря 2026 года | `7690641f5948c872dbd5101e72e0ce4b54ab6ea3e22349f92789694890fb3fff` |
| `services.csv` | Проверка рейсов для схемы | `b130b7dd4fa29ca2f7b48f28a8ef7a26887563aa437b93eb9c6a8915d869b545` |

## Метод и результаты

Граф содержит 180 городов по UUID и 482 направленные связи `air`. У 72 городов
есть хотя бы одна входящая или исходящая авиасвязь. Обход в ширину проверяет,
есть ли путь по прямым авиасвязям. В обоих вариантах возможные отправления и
назначения — одни и те же 179 городов без Москвы. Пары города с собой
исключены. До удаления Москва может быть промежуточной вершиной.

| Показатель | Значение | Единица |
|---|---:|---|
| Достижимы в исходном графе | 4 900 | направленные пары |
| Достижимы после удаления Москвы и её рёбер | 3 660 | направленные пары |
| Потеряли путь | 1 240 | направленные пары |
| Доля потерянных среди исходно достижимых | 25,3 | % |

Проверено 23 ноября 2026 года на Python 3.12.3. Два прогона команды дали
одинаковый JSON. Независимый расчёт транзитивного замыкания на тех же данных
подтвердил оба числа достижимости.

## Материал для слайдов 10–11

**Результат по сети.** «Без Москвы» достижимы 3 660 из 4 900 направленных пар
между остальными городами. Потеря — 25,3%. Источник для подписи —
Яндекс Расписания, расписание на 1 декабря 2026 года.

**Пример по расписанию.** Абакан → Шереметьево → Грозный, 1 декабря 2026 года.
SU-1479 прибывает в Шереметьево в 11:00 МСК, SU-1496 вылетает оттуда в
15:25 МСК. Интервал между рейсами — 4 ч 25 мин.

![Абакан → Шереметьево → Грозный](../../docs/diagrams/yandex-air-resilience.svg)

SHA-256 `services.csv` совпал с отчётом нормализации. Обе строки имеют дату
отправления `2026-12-01`, а станция прибытия SU-1479 и вылета SU-1496
совпадает с кодом Шереметьево `s9600213` в `stations.csv`. Время прилёта
получено из `departure_at + duration_sec` и сверено с сохранённым ответом API.
Время вылета также сверено с ответом API. В графе путь Абакан → Грозный
исчезает после удаления Москвы.

Сетевой расчёт учитывает существование пути по рёбрам. Возможность поездки
с пересадками требует отдельной проверки расписаний и условий стыковки.
