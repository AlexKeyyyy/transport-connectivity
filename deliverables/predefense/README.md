## Как показать результат

1. На подготовленном компьютере открыть карту с JSON из команды
   `python scripts/dev/export_map_accessibility.py`. При необходимости
   создать его с нуля через `download` и `process`.
2. Запустить `python -m streamlit run src/transport_connectivity/app/map_app.py`.
   Выбрать Москву, «Лучший из трёх», 6 часов. Проверить 101 строку направлений.
3. На слайде 10 объяснить, почему при удалении Москвы из каркаса матрицы
   сохранились пути. На слайде 11 показать 4 900 → 3 660 для наблюдаемых
   авиасвязей и отдельный пример Абакан → Шереметьево → Грозный.
4. При недоступной подложке показать слайд 12 со скриншотом. Для авиачасти
   использовать слайд 11. Эти эпизоды не требуют новых запросов к API.

Для обновления PDF откройте соответствующий HTML в Chrome или Edge.
При печати в PDF выберите масштаб 100%, поля «Без полей» и фоновые
изображения. Отключите колонтитулы браузера. CSS задаёт формат 16:9 для
слайдов и A4 для отчёта. После экспорта проверьте число страниц, переносы
и ссылки. Изображение карты ссылается на файл в этом репозитории.
