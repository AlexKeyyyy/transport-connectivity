# Воспроизводимый транспортный pipeline

Прочитай [источники](../../../docs/data-sources.md), контракт текущего Issue и
[архитектуру](../../../docs/architecture.md). Не расширяй пилот на live API без задачи.

## Вход и преобразования

- Согласуй namespace внешних ID и устойчивый ключ. Название города не ключ;
  ОКТМО, Sber ID, OSM и коды Яндекса различаются. Не выдумывай отсутствующие ID.
- Явно фиксируй CSV encoding/delimiter, схему, обязательные поля и единицы.
  Часы умножаются на 3600, километры на 1000. Проверяй finite-числа: NaN/inf
  не являются корректным расстоянием или временем.
- Допустимый пропуск маршрута сохраняется с причиной. Незапрошенная пара,
  ошибка API и подтверждённое отсутствие маршрута — разные состояния.
- Согласуй, отклоняется ли вся строка или отдельная метрика при частичной ошибке.
  Если контракта ещё нет, обозначь предлагаемую политику до реализации.
- При изменении схемы останови неподходящий этап с диагнозом; не теряй поля молча.

## Загрузка и публикация

Manifest: URL/версия, UTC-время, SHA-256 точных входных байтов, размер и фактический
объём. Используй временный файл, проверку и завершённую публикацию вместо
успешного кэша из частично скачанного ответа. Ограничивай retries; учитывай квоты,
pagination и Retry-After, когда это относится к API текущей задачи.

Повторная загрузка/обработка того же входа не накапливает записи. Большие raw и
processed не входят в Git. Параметры без ключей и локальных абсолютных путей.

## Приёмка

Небольшие offline-fixtures покрывают направление A→B/B→A, единицы, неоднозначные
ID, пропуски, невалидные числа и повторный запуск. Для коннектора добавь кэш,
таймаут и повреждённый архив. Проверяй семантический ключ дубликата, не только
равенство всей строки. Категории баланса должны быть непересекающимися:

`вход = сохранённые + отклонённые + удалённые дубликаты`.

Полный прогон подтверждает run-report: входной hash, commit/параметры, UTC,
баланс, пропуски, время и пиковая память с методом измерения. Baseline 96 660
из источника — контроль для конкретной версии, а не hardcoded лимит обработчика.
Не объявляй полный прогон по smoke-тестам или выполнению только sample.
